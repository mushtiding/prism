# Prism product language

Prism helps people compare how deliberately biased market perspectives interpret
the same evidence. Names prioritize clarity in a financial context while keeping
the lens metaphor that belongs to the Prism brand.

## Core vocabulary

| Concept | UI name | Usage |
| --- | --- | --- |
| Product | Prism | Keep as the product name. |
| Current generated analysis | Brief | Daily brief, your brief, saved brief. |
| Evidence-backed news items | Market drivers | Avoid generic "key points" or "moves." |
| Character opinions | Perspectives or views | Use perspective for the collection and view for one character's response. |
| Perspective spread metric | Disagreement score | Always include the 0-1 range near the score. |
| Independent reconsideration | Second View | Never imply a discussion or consensus. |
| Saved generated briefs | Archive | Contains existing briefs only; it never generates past dates. |

## Primary destinations

- **Today:** the latest daily brief.
- **Your Brief:** a brief created from the user's selected finance articles.
- **Archive:** saved versions of previously generated daily briefs.

## Action grammar

- Use verbs for controls: **Update brief**, **Create brief**, **Generate second
  views**, **Open brief**, **Try again**.
- Use nouns for destinations and content: **Your Brief**, **Market drivers**,
  **Selected articles**, **Second views**.
- Do not expose implementation language such as "refracting," "model," persona
  calls, queues, or cache behavior.

## Terms retained intentionally

- **Lens** remains acceptable in explanatory brand copy and internal naming, but
  primary UI labels use **perspective** or **view** for immediate clarity.
- Character names Blitz, Sprout, Penny, Sage, and Nix remain distinctive and are
  always paired with their market archetype.
- Bullish, bearish, neutral, source, and finance article remain standard market
  terms and should not be replaced with branded synonyms.
