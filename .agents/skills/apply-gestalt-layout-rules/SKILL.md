# Apply Gestalt Layout Rules

Shape a layout around how viewers naturally group, simplify, and follow visual information. Use the rules together, then verify that the intended message remains the clearest reading.

## Quick reference

| Topic | Use when |
| --- | --- |
| Similarity | Elements should read as one system or one item must stand apart |
| Proximity | Related content needs to be understood as a group |
| Simplicity | A layout, icon, or message feels busy or unclear |
| Figure and ground | The focal subject does not separate from its context |
| Symmetry and order | A composition feels lopsided or unstable |
| Closure | Negative space can imply a complete form |
| Experience | A design relies on familiar conventions or breaks them deliberately |
| Continuation | The viewer’s eye needs a clear route through the layout |

## Core principles

### 1. Group by similarity

Use shared color, texture, shape, position, orientation, or size to make related elements read as a set.

### 2. Group by proximity

Place related items closer to one another than to unrelated items.

### 3. Reduce to the simplest useful form

Remove or combine anything that does not strengthen the core message.

### 4. Separate figure from ground

Use contrast and context to make the current focal element read unmistakably as foreground.

### 5. Establish balance with symmetry and order

Distribute visual weight deliberately so the composition resolves as a stable whole.

### 6. Let closure complete partial forms

Use carefully placed gaps and negative space when the surrounding cues are sufficient for the viewer to complete the form.

### 7. Respect experience, then break it with intent

Follow learned conventions for comprehension; violate one only when the resulting pause supports the message.

### 8. Guide the eye with continuation

Create smooth visual paths that lead the viewer toward the next important message.

## Workflow

### 1. Define the reading

- State the single most important message.
- List the intended scan order and semantic groups.

### 2. Build the structure

- Group related elements with similarity and proximity.
- Establish figure–ground separation and balanced visual weight.

### 3. Shape attention

- Use continuation to connect the reading sequence.
- Use contrast or a controlled break from convention to emphasize the focal point.

### 4. Reduce and test

- Remove elements that do not add value.
- Test recognition, grouping, and flow at the final size.

## Review checklist

- [ ] The focal message is the first stable reading.
- [ ] Related elements share a visual trait and sit closer together than unrelated elements.
- [ ] Foreground and background remain distinct at the final size.
- [ ] Visual weight feels intentional rather than accidentally lopsided.
- [ ] The eye has a smooth path through the intended sequence.
- [ ] Every remaining element adds value to the message.
- [ ] Any broken convention is recoverable and earns useful attention.

## Glossary

- **Figure:** The form currently perceived as the foreground subject.
- **Ground:** The field perceived as background around the subject.
- **Closure:** The tendency to perceive an incomplete contour as a complete form.
- **Continuation:** The tendency to follow the smoothest visual path.
