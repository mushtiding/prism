# composition

Detailed, source-backed guidance for composition.

## Establish balance with symmetry and order

**Rule:** Distribute visual weight deliberately so the composition resolves as a stable whole.

The mind seeks completion, balance, and ordered units.
### Apply it

1. Compare visual weight across the main axis.
2. Balance shapes, type, or content blocks.
3. Use asymmetry only when another element restores equilibrium.
### Examples

- Balance article titles across both sides of a magazine cover instead of stacking all of them on one side.
### Common mistakes

- Adding weight to one side of a mark without a counterweight makes it feel lopsided.

## Let closure complete partial forms

**Rule:** Use carefully placed gaps and negative space when the surrounding cues are sufficient for the viewer to complete the form.

The mind fills missing contours and prefers the simplest complete explanation.
### Apply it

1. Start with a familiar form.
2. Remove only the portions the viewer can infer.
3. Test recognition at the final viewing size.
### Examples

- Form a hidden letter in the negative space between positive shapes in a logo.
### Common mistakes

- Removing too much context turns an elegant implied form into an unreadable puzzle.
