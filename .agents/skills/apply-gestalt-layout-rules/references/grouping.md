# grouping

Detailed, source-backed guidance for grouping.

## Group by similarity

**Rule:** Use shared color, texture, shape, position, orientation, or size to make related elements read as a set.

Viewers categorize similar objects even when those objects are not adjacent.
### Apply it

1. Choose the visual attribute that signals membership.
2. Apply it consistently to related elements.
3. Make the focal element meaningfully different from the set.
### Examples

- Use consistent image shapes across a layout, then change the key item’s color to draw attention.
### Common mistakes

- Mixing unrelated shapes without a grouping logic creates categorization noise.

## Group by proximity

**Rule:** Place related items closer to one another than to unrelated items.

Spacing communicates relationships before a viewer reads the content.
### Apply it

1. Identify semantic groups.
2. Tighten spacing within each group.
3. Increase space between unrelated groups.
### Examples

- Keep an event name with its descriptor, and group date with location.
### Common mistakes

- Putting all information into one evenly spaced area makes the layout intimidating and hard to scan.
