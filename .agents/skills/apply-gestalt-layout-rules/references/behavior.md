# behavior

Detailed, source-backed guidance for behavior.

## Respect experience, then break it with intent

**Rule:** Follow learned conventions for comprehension; violate one only when the resulting pause supports the message.

Viewers interpret new designs through familiar patterns and locations.
### Apply it

1. List the relevant conventions.
2. Keep conventions that enable basic use or reading.
3. If surprise is useful, break one convention while preserving enough cues to recover.
### Examples

- Keep links visibly differentiated; make a headline’s direction unexpected to earn attention.
### Common mistakes

- Making essential controls dramatically different from expectation creates confusion rather than interest.

## Guide the eye with continuation

**Rule:** Create smooth visual paths that lead the viewer toward the next important message.

The eye tends to continue along a smooth path across intersections and interruptions.
### Apply it

1. Choose the intended reading sequence.
2. Align edges, curves, gestures, or gazes along that route.
3. Remove tangents that pull attention away.
### Examples

- Aim a model’s gaze toward the headline, then lead from the headline down to the product.
### Common mistakes

- Pointing a subject’s gaze away from the next element breaks the layout’s natural flow.
