# clarity

Detailed, source-backed guidance for clarity.

## Reduce to the simplest useful form

**Rule:** Remove or combine anything that does not strengthen the core message.

The mind prefers simple forms and can recognize them reliably at smaller sizes.
### Apply it

1. Name the main message or focal point.
2. Ask whether each element adds value.
3. Remove redundant graphics and combine repeated text.
4. Test that the reduced form retains its meaning.
### Examples

- Reduce a detailed illustration to a recognizable icon that survives at small sizes.
### Common mistakes

- Simplifying until the object loses its core meaning trades clutter for ambiguity.

## Separate figure from ground

**Rule:** Use contrast and context to make the current focal element read unmistakably as foreground.

Viewers rapidly assign forms to foreground and background to decide where to focus.
### Apply it

1. Choose the focal element.
2. Increase its contrast against the surrounding field.
3. Subdue unrelated elements.
4. Check that the intended figure is the first stable reading.
### Examples

- Darken the page behind a newsletter modal so the lighter modal becomes the foreground.
### Common mistakes

- Equal emphasis between subject and background makes the viewer lose the intended focus.
